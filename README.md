# 背背文

An online memorization and recitation website for classical texts, poetry, scripture, mathematics, and traditional performance materials.

This project organizes a wide range of content into a simple static website, making it easier for users to browse, practice, and memorize different types of material.

## Live Site

[View Website](https://celine10811020.github.io/BeiGuanKou/)

## About the Project

It is a web-based platform designed for memorization practice.

The site collects and organizes multiple categories of content, including:

- traditional elementary texts
- Chinese classics prose
- Chinese classics poetry
- Bible passages
- mathematics constants
- traditional fast-tongue routine

Instead of focusing on a single topic, this project serves as a general-purpose memorization resource library.
